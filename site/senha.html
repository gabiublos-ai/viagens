Gerar a senha de acesso
Gestão de Viagens · Ace Gaming
Escolha a senha que a equipe vai usar para entrar. Ela é transformada aqui mesmo, no seu navegador — não é enviada para lugar nenhum. O que você copia e cola no Netlify são os dois valores gerados, dos quais não dá para voltar à senha original.
Uma frase curta funciona melhor que uma palavra difícil de lembrar.
SENHA_HASH

SESSAO_SEGREDO

1 No Netlify, abra o site → Site configuration → Environment variables.
2 Crie as duas variáveis acima, com exatamente esses nomes, colando cada valor.
3 Em Deploys, clique em Trigger deploy → Deploy site.
4 Pronto: abra o app e entre com a senha que você escolheu.
